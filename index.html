How to test
  1. Host on HTTPS (GitHub Pages) and open in Chrome on Android. iPhone Safari lacks Web Bluetooth (IMU and simulator still work).
  2. Disconnect Bora from XCTrack/FlyGineer first – one BLE connection at a time.
  3. Tape Bora to the phone so both feel the same motion.
  4. Still for 10 s → compare jitter. Lift ~1 m up/down, stairs or elevator → compare lag.
  5. Turn test: walk in tight circles holding the pair tilted ~30°. Baro + acc will show false climb/sink; baro + acc + gyro should stay put.
  6. Record a real flight with the phone in the cockpit and replay it with different tuning.
Baro + acc = what Bora gets with just an accelerometer. Baro + acc + gyro = this page's own Mahony filter on raw gyro + accel, i.e. what Bora would compute with a 6-axis IMU (no magnetometer). Baro + OS fusion = Android's own orientation sensor, the reference.
